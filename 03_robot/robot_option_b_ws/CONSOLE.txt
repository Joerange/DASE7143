2. 界面与距离含义

顶部固定显示任务状态、真实里程计速度、新鲜度、CAN 状态、底盘通信和保护原因。
CAN=UP 只表示接口状态，不表示底盘通信正常，也不表示已允许运动。
速度显示来自新鲜里程计；过期、没有通信或读取失败时显示“未知 / 不可用”。

RGB：检测框只叠加到时间戳一致的原始RGB图像；选定目标使用黄色强调。
检测结果尚未找到同帧图像时不在新图像上套用旧框。
深度：光轴深度 Z 与“物理车头到目标表面的净距”分开显示。
车头参考 x=0.345m，当前任务停车目标10cm、软件到达区间8–12cm；观测过期会明确标注。
LiDAR：base_link 坐标下车头向上、车体左侧向左，圆环每1m。
扫描若仍是 laser_link 等其他坐标系，不会直接与车体轮廓叠加。
地图：蓝色车体及路径、黄色目标、绿色停靠点、灰色未知空间。
地图扩展和原点变化按当前分辨率、原点及旋转重新投影，不固定像素偏移。

传感器状态显示等待、正常、过期或断流，并附消息年龄与接收频率。
本机后台断开时，按钮除显式停止请求外全部禁用，速度/CAN/底盘通信标为未知；
保留图像只供查看。重新连接后以后台实际状态回读恢复，不根据上一次点击猜测成功。

事件时间线区分本地检测、VLM回答、本地任务/安全决策和系统操作。
可查看 task_generation、geometry_epoch、observation_id、request_id、响应耗时及错误。
候选被确认不等于获准前进；本地定位、已知自由空间路径、停稳及安全条件仍需同时满足。

3. 控制按钮与后台回读

启用 CAN：只申请配置既定 can0/500000，不启动底盘或任务，不授予运动权限。
启动底盘驱动：与启用CAN分开；后台核验CAN、最终安全节点状态并避免重复驱动。
允许任务运动：申请独立安全节点授权；实际底盘通信、传感器、定位和Nav2必须就绪。
开始任务：单独人工触发，不因CAN、驱动或运动权限就绪而自动开始。
停止任务 / 撤销运动：撤销独立保护授权并请求任务/导航停止，再核验实测停稳。
停止驱动 / 关闭 CAN：先撤销运动、取消导航、验证持续停稳及实时CAN反馈，
  再终止由受控后台管理的底盘驱动；仅关闭CAN操作继续执行受限接口关闭并回读。
  不能确认停稳、驱动不是后台所有、数据过期或操作超时时，不把CAN关闭当作停车替代。

“已提交 / 处理中”只表示请求进入后台，不代表动作成功。
顶部操作状态和时间线区分“已确认 / 失败 / 结果未知”。停止超时不会显示“已停稳”；
CAN关闭失败不会显示“已关闭”。此时保留保护约束并查询实际状态。

导出日志：导出当前任务对应的事件记录，默认保存到 ~/robot_option_b_ws/console_exports。
后台返回操作ID，最终成功状态包含实际文件路径；事件包含状态/操作结果和候选关联信息，
不导出API密钥、原始图像、请求正文或模型提示词。感知关键帧留存仍由原感知节点负责。

4. 权限与部署状态

普通查看后台不具有CAN管理权限，CAN/底盘启动/允许运动/任务启动按钮不可用。
如果系统中已运行经审阅安装的受控后台，窗口会连接它并显示“受控服务”；
可用操作由后台当前权限和前置条件决定。启动窗口本身不改变这些权限。

受限CAN helper、普通用户控制服务和systemd部署材料位于 console_service/。
helper只接受指定服务进程的固定接口操作，不执行任意shell命令，不接受界面传入的
“已经停稳”标志作为证据。界面不直接调用helper，不发布 /cmd_vel。
部署材料的生成不等于已经安装或启动；本次未执行提权安装、启用CAN或启动实车底盘。

管理员在明确授权后可先审阅并检查：
  ./console_service/install_services.sh --check
实际安装命令及信任边界见 console_service/HELPER_PROTOCOL.txt。
安装是独立步骤；安装脚本本身不启动或启用服务、CAN、底盘或任务。
后台重启、窗口关闭和helper退出都不会自动关闭CAN来冒充已验证停车。

受控服务采用独立的 /run/user/1000/robot-console-control.sock；只读后台使用
/run/user/1000/robot-console.sock。桌面启动脚本优先连接已运行的受控服务，
否则连接或创建只读后台。部署服务不会把已有只读后台变为控制后台。
完成管理员审阅和现场许可后，部署步骤为：
  sudo ./console_service/install_services.sh --install
  sudo systemctl start robot-console-can.service robot-console.service
这两条命令本次未执行；不会设置开机自启。服务启动本身不启用CAN、底盘或任务。
另按 README.txt 启动同域、allow_runtime_control=true 的任务栈，再打开控制台。
